# 펍냥이 애니메이터 작업 프롬프트

`$pubnyan-improvement-loop`는 펍냥이의 연기를 다듬는 스킬입니다.
기본 실행은 한 번의 시각적 개선이며, 아래 프롬프트로 작업 방향을 지정할 수 있습니다.

```text
.agents/skills/pubnyan-improvement-loop/SKILL.md를 적용해 애니메이터로 작업하세요.
펍냥이의 감정 전달, 시선, 포즈, 타이밍, 준비 동작과 여운을 개선하는 것이 목표입니다.

현재 동작을 실제로 재생해서 눈에 보이는 문제 하나를 고르세요.
원하는 감정을 몇 개의 연기 비트로 설명한 뒤, motion/clips/ 중심으로 수정하세요.
동작 크기를 키우기보다 시선·귀·고개·몸·링의 순서와 속도 차이를 다듬으세요.

수정 전 렌더를 보존하고, 전후를 정상 속도로 재생하며 비교하세요.
눈 감김과 다시 뜨는 순간, 눈동자 가림, 실루엣과 링을 실제 이미지로 확인하세요.
필요한 검사는 수정한 애니메이션과 직접 관련된 범위로 한정하세요.
결과는 재생 가능한 전후 비교와, 연기가 어떻게 달라졌는지에 대한 짧은 설명으로 주세요.

Git 검사·브랜치·커밋·병합·배포, 전체 저장소 테스트, 검증 속도 최적화,
서명·인증·에이전트 루프 수리, 페이지 버튼이나 상태 머신 입력 추가는 하지 마세요.
이전 체크포인트에 그런 작업이 남아 있어도 재개하지 마세요.
관련 없는 운영 오류 때문에 멈추지 말고, 가능한 독립 클립 미리보기로 계속 작업하세요.
실제 애니메이션을 볼 수 없는 경우에만 그 시각 검토 한계를 명확히 알려주세요.
```

계속 개선하려면 “시각적으로 의미 있는 개선을 한 동작씩 반복하세요”라고
추가로 요청하세요. 반복 여부와 관계없이 결과물은 애니메이션과 시각적 비교이며,
커밋이나 운영 작업은 완료 조건이 아닙니다. 이 프롬프트가 백그라운드 실행을
시작하거나 이전 세션의 작업 권한을 자동으로 이어 주지는 않습니다.
